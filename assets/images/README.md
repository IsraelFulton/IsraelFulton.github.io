# Images

If your avatar filename contains spaces (for example, `Fulton, Israel Picture 1.jpeg`),
use URL encoding in `_data/authors.yml`:

```
avatar: "/assets/images/Fulton,%20Israel%20Picture%201.jpeg"
```

You can also rename the file to something simpler like `avatar.jpeg` and update the
path accordingly.
Replace `avatar.svg` with your profile picture (you can keep the filename to avoid
changing configuration) or update the `avatar` path in `_data/authors.yml`.
